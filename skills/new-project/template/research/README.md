# research

Finished research: one Markdown report per question, written with the research-report skill. An HTML version can be generated into `docs/visual/` on request.

- **Goes in:** finished reports only.
- **Doesn't go in:** notes, drafts, raw sources or unfinished research; documents from the team (→ `inputs/`); general explanations of concepts (→ `docs/concepts/`).
- **Naming:** `YYYY-MM-DD-topic.md`, lower case with hyphens: `2026-03-14-auth-provider.md`.
- **Updated:** each time a report is finished, a row is added below. Claude reads this table instead of opening the reports, and opens a report only when the table isn't enough.
