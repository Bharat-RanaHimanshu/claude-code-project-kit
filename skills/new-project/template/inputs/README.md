# inputs

Documents the team gave me: requirements, plans, designs, client documents, anything handed over from outside.

- **Goes in:** documents received from other people, kept exactly as received.
- **Doesn't go in:** my own notes, drafts or research (→ `docs/`, `research/`), or anything Claude generates.
- **Naming:** keep the original file name. If a new version of the same document arrives, add the date received: `requirements-2026-03-14.pdf`.
- **Updated:** when a new document arrives. Claude never edits, moves or deletes these files. It only adds a row to the table below.
