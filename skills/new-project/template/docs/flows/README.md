# flows

One doc per end-to-end journey (for example, from sign-up to the first order), written with the deep-doc skill.

- **Goes in:** `<journey>.md`, following the deep-doc outline, usually with a sequence diagram.
- **Doesn't go in:** the details of a single feature (→ `../features/`), plans (→ `session/plans/`), generated HTML (→ `../visual/`).
- **Naming:** the journey, lower case with hyphens: `checkout.md`, `sign-up-to-first-order.md`. No dates.
- **Updated:** whenever any step of the journey changes. Add or update its row in `docs/README.md` at the same time.
