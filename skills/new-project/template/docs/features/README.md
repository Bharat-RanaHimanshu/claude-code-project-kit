# features

One detailed doc per feature, written with the deep-doc skill.

- **Goes in:** `<feature>.md`, one per user-facing feature or capability, following the deep-doc outline.
- **Doesn't go in:** end-to-end journeys that cross several features (→ `../flows/`), plans (→ `session/plans/`), generated HTML (→ `../visual/`).
- **Naming:** the feature name, lower case with hyphens: `password-reset.md`. No dates; these are living docs.
- **Updated:** whenever the feature's behaviour changes. Add or update its row in `docs/README.md` at the same time.
