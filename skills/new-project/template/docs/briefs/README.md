# briefs

One-page, plain-language summaries for the team head, written with the status-brief skill.

- **Goes in:** dated briefs as Markdown. An HTML version is generated into `../visual/` when one is asked for.
- **Doesn't go in:** detailed docs, technical notes, anything with code.
- **Naming:** `YYYY-MM-DD-topic.md`, for example `2026-03-14-weekly-status.md`.
- **Updated:** never. Each brief is a snapshot; write a new one instead of editing an old one. Add a row to `docs/README.md` for each new brief.
