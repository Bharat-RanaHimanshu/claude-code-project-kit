# concepts

One doc per concept the project relies on (for example JWT, database indexes, the event loop), written with the deep-doc skill, kind `concept`. These explain the idea in general, then show where it appears in this project, so they stay useful in later projects.

- **Goes in:** `<concept>.md`, following the deep-doc concept outline.
- **Doesn't go in:** how this project's features work (→ `../features/`), choices between options (→ `research/` and `../decisions.md`).
- **Naming:** the concept, lower case with hyphens: `jwt.md`, `database-indexes.md`. No dates.
- **Updated:** when the project uses the concept in a new way, or a misunderstanding is corrected. Add or update its row in `docs/README.md` at the same time.
