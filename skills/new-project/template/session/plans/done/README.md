# done

Finished plans, kept as a record of how each feature was built.

- **Goes in:** plans whose feature met the definition of done, moved here from `plans/` (with `git mv`, so the history follows). Abandoned plans also come here, with status `abandoned` and one line on why.
- **Doesn't go in:** active plans (→ `../`).
- **Naming:** unchanged from `plans/`. If the name is already taken here, add the finish date: `password-reset-2026-05-01.md`.
- **Updated:** never edited after the move.
